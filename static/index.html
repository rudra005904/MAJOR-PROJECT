Preparing the Image: Preprocessing Pipeline (Slide 7)

To ensure reliable pattern classification across diverse biometric sensors, input images pass through standard image cleanup and dataset preparation before entering the neural network.

1. Grayscale & Fixed Resolution

Color scans are converted to single-channel 8-bit grayscale and standardized to 128×128 pixels using anti-aliased interpolation.

2. Noise Attenuation & Ridge Contrast

Sensor grain and platen dirt are attenuated via Gaussian filtering. CLAHE (Contrast Limited Adaptive Histogram Equalization) boosts local ridge-valley gradient definition.

3. Fingerprint Region Segmentation

Otsu automated thresholding and morphological closing extract the active fingerprint area from blank background paper or scanner borders.

4. Pixel Normalization & Batching

Pixel intensities are normalized to the [0.0, 1.0] floating point range to ensure rapid gradient descent convergence during CNN backpropagation.

Learning the Pattern: CNN Architecture (Slide 8)

The hierarchical convolutional neural network learns discriminative features directly from raw ridge patterns end-to-end, removing hand-crafted minutiae rules.

Hierarchical Feature Flow

Input Layer
Grayscale Fingerprint Scan Tensor
Shape: [1, 128, 128]
Stage 1: Local Ridge Orientation & Curvature
2× Conv2D(32 channels, 3×3) + BatchNorm + ReLU + MaxPool2D(2×2)
Shape: [32, 64, 64]
Stage 2: Intermediate Recurvature & Ridge Flow
2× Conv2D(64 channels, 3×3) + BatchNorm + ReLU + MaxPool2D(2×2)
Shape: [64, 32, 32]
Stage 3: Core & Delta Pattern Structures
2× Conv2D(128 channels, 3×3) + BatchNorm + ReLU + MaxPool2D(2×2)
Shape: [128, 16, 16]
Stage 4: Global Pattern Topology
Conv2D(128 channels, 3×3) + AdaptiveAvgPool2D(4×4)
Shape: [128, 4, 4]
Classification Head & Softmax
Flatten (2048) -> Dense(128) + ReLU + Dropout(0.35) -> Dense(3) + Softmax
3 Classes: Arch, Loop, Whorl

Known Challenges and How to Address Them (Slide 14)

Challenge Engineering Mitigation (Implemented)
Limited or imbalanced training data Data augmentation (rotation, affine shift, contrast) & inverse class-weighted loss.
Similar inter-class patterns (loop vs. whorl) Near-miss borderline margin inspection & confusion-matrix error tracking.
Variable image quality (smudges, partial prints) Adaptive CLAHE ridge contrast enhancement & Otsu region segmentation.
Overfitting on small dataset Dropout (0.35), batch normalization, and early stopping with patience on validation loss.
Compute cost of training Compact lightweight 4-stage CNN architecture capable of fast convergence.
